# **wetland-suitability_est-rf-ahp-2025**

This repository provides the **code supplement and data references** for the paper  
**“In-stream wetland suitability mapping using Analytic Hierarchy Process and machine learning.”**  
The study focuses on identifying suitable locations for **in-stream wetland creation and restoration** in Estonia.

The repository implements and compares an **expert-based Analytic Hierarchy Process (AHP)** approach and a **data-driven Random Forest (RF)** machine learning model, with particular emphasis on the effects of **data source (local vs. global)** and **spatial resolution (10 m vs. 50 m)** on suitability mapping performance. The content is intended to support **methodological transparency and reproducibility** of the modelling framework presented in the paper.

## **Folders and files**

- **`data/`**: references to local and global input datasets (10 m and 50 m), along with `environment.yml` files for setting up the computational environment  
- **`model_rf/`**: scripts and notebooks for training, validation, and spatial prediction using the Random Forest model  
- **`model_ahp/`**: scripts, weighting matrices, and workflows used for AHP-based suitability modelling  
- **`validation/`**: model evaluation routines, including ROC–AUC analysis and comparison against historical wetland maps  

## **Code supplement**

This code supplement implements **expert-based (AHP)** and **machine learning (Random Forest)** workflows for mapping **in-stream wetland suitability** and for systematically comparing modelling approaches, data sources, and spatial resolutions.
